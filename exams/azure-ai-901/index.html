Sample Q1 · Domain 1: Identify AI Concepts and Capabilities SINGLE-SELECT

A global logistics carrier wants an AI system that receives a delayed-shipment alert, autonomously queries carrier weather feeds, recalculates delivery SLAs, calls an ERP API to rebook freight capacity, and emails affected customers without human intervention at each intermediate step. Which AI workload paradigm best describes this capability?

  1. A. Robotic Process Automation (RPA) executing fixed UI click macros.
  2. B. Agentic AI orchestrating reasoning, memory, and multi-step tool execution.
  3. C. Classical supervised regression forecasting transit duration from historical tables.
  4. D. Single-turn extractive question answering over static SOP manuals.
Reveal Verified Answer (B), Technical Explanation & Exam Hack

Correct Answer: Option B

Option B is correct because Agentic AI systems combine a foundation model's reasoning with persistent state/memory and autonomous tool calling (APIs, search, code execution) to plan and complete multi-step goals dynamically. Option A fails because traditional RPA follows brittle, deterministic UI scripts and cannot reason over unstructured weather alerts or adapt plans when exceptions occur. Option C fails because supervised regression only outputs a numeric prediction rather than invoking external APIs or composing communications. Option D fails because single-turn extractive QA merely returns a text span from a document with no planning or action execution.

Production Use Case: Supply-chain operations teams build autonomous disruption-resolution agents in Azure AI Agent Service using OpenAPI tools for ERP rebooking and Grounding with Bing Search for live port and weather advisories.
Exam Hack: Autonomous multi-step planning + calling external tools/APIs + adapting to intermediate results = Agentic AI.
Sample Q2 · Domain 2: Implement AI Solutions by Using Microsoft Foundry SINGLE-SELECT

An enterprise cloud platform team is onboarding three separate business units (Retail, Wealth Management, and Claims) into Microsoft Foundry. All three teams must share a centralized Private Link network topology, enterprise Azure Key Vault, and approved model connections, while keeping each team's prompt flows, evaluation runs, uploaded datasets, and developer RBAC strictly isolated. How should the team structure Microsoft Foundry?

  1. A. Create one Foundry Project and place three Foundry Hubs inside it.
  2. B. Create a single Foundry Hub and a single Foundry Project shared by all three business units.
  3. C. Create one Foundry Hub for shared security, networking, and connections, and three separate Foundry Projects under that Hub.
  4. D. Deploy three standalone Azure AI Services accounts without a Foundry Hub or Projects.
Reveal Verified Answer (C), Technical Explanation & Exam Hack

Correct Answer: Option C

Option C is correct because a Microsoft Foundry Hub is the top-level governance container that centralizes shared networking (VNet/Private Endpoints), compute, security settings, and external connections, while child Foundry Projects provide isolated workspaces for team-level assets, evaluations, files, and RBAC assignments. Option A fails because Hubs contain Projects, never the reverse. Option B fails because a single Project does not isolate prompt flows, datasets, or developer RBAC between business units. Option D fails because standalone AI Services accounts lack Foundry's unified project governance, evaluation, and agent workspace.

Production Use Case: Platform engineering teams provision one Hub per environment (dev/prod) via Bicep or Terraform and stamp out dedicated Foundry Projects for each product squad with scoped Azure AI Developer RBAC.
Exam Hack: Foundry Hub = shared security, networking, compute, and connections; Foundry Project = isolated team workspace for assets, runs, and scoped RBAC.
Sample Q3 · Domain 1: Identify AI Concepts and Capabilities SINGLE-SELECT

During pre-release auditing of a retail bank's automated mortgage pre-qualification model, data scientists discover that applicants with identical credit scores and debt-to-income ratios receive 18% lower approval rates when their residential postal code historically correlates with lower-income neighborhoods. Which Microsoft Responsible AI principle is most directly violated?

  1. A. Fairness.
  2. B. Inclusiveness.
  3. C. Transparency.
  4. D. Privacy and Security.
Reveal Verified Answer (A), Technical Explanation & Exam Hack

Correct Answer: Option A

Option A is correct because Microsoft's Fairness principle requires AI systems to treat similarly situated people equitably and avoid allocative harm or proxy discrimination (such as postal codes acting as socioeconomic proxies in lending). Option B fails because Inclusiveness focuses on empowering diverse populations and accessibility (e.g., disabilities, languages, accents) rather than disparate lending outcomes for identical profiles. Option C fails because Transparency concerns disclosing how the system works and its limitations, not the underlying discriminatory disparity itself. Option D fails because Privacy and Security addresses protecting personal data confidentiality and defending against unauthorized access.

Production Use Case: Financial institutions evaluate tabular models with Fairlearn disparity metrics and remove proxy features like ZIP/postal codes before promoting lending models through governance gates.
Exam Hack: Unequal outcomes or proxy bias affecting comparable individuals (loans, hiring, sentencing) = Fairness.
Sample Q4 · Domain 2: Implement AI Solutions by Using Microsoft Foundry SINGLE-SELECT

An aviation engineering firm using the Microsoft Foundry Model Catalog needs to deploy a single foundation model endpoint that inspects uploaded photographs of turbine blade cracks alongside maintenance PDFs and generates detailed inspection notes. Which model from the Foundry Model Catalog is the best fit for native vision-plus-text multimodal analysis?

  1. A. text-embedding-3-large.
  2. B. Cohere Rerank v3.
  3. C. Whisper.
  4. D. GPT-4o.
Reveal Verified Answer (D), Technical Explanation & Exam Hack

Correct Answer: Option D

Option D is correct because GPT-4o is a native multimodal foundation model in the Microsoft Foundry Model Catalog capable of reasoning jointly over images (such as turbine blade photos) and text instructions to generate structured inspection reports. Option A fails because text-embedding-3-large only converts text into numerical vectors for semantic search and cannot analyze images or generate text. Option B fails because Cohere Rerank reorders search results by relevance rather than processing images or writing prose. Option C fails because Whisper is an automatic speech-to-text audio transcription model.

Production Use Case: Field-service inspection apps send high-resolution equipment photos and checklist prompts to GPT-4o deployed in Microsoft Foundry to draft standardized maintenance work orders.
Exam Hack: Native image + text multimodal reasoning in Foundry Model Catalog = GPT-4o (or Phi-4-multimodal for lightweight edge/SLM cases).
Sample Q5 · Domain 1: Identify AI Concepts and Capabilities SINGLE-SELECT

A commercial real-estate energy company has five years of historical hourly building data including outdoor temperature, occupancy count, HVAC setpoint, and the exact kilowatt-hours (kWh) consumed. The team wants a model that predicts tomorrow's exact continuous kWh demand for each building. Which machine learning technique should they use?

  1. A. Binary classification.
  2. B. K-Means clustering.
  3. C. Supervised regression.
  4. D. Named Entity Recognition.
Reveal Verified Answer (C), Technical Explanation & Exam Hack

Correct Answer: Option C

Option C is correct because predicting a continuous numerical value (exact kWh demand) from historical labeled features (temperature, occupancy, HVAC setpoint) is the textbook definition of supervised regression. Option A fails because binary classification predicts one of two discrete categories (such as outage vs. normal), not a continuous quantity. Option B fails because K-Means clustering is an unsupervised method used to group unlabeled observations rather than predict a known target number. Option D fails because Named Entity Recognition extracts entities from unstructured text.

Production Use Case: Smart-grid utilities train gradient-boosted regression models on weather and smart-meter histories to forecast 24-hour continuous energy load and optimize peak generation dispatch.
Exam Hack: Historical labeled data + predicting a continuous number (price, kWh, temperature, revenue) = Supervised Regression.
