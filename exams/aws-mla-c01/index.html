Sample Q1 · Domain 1: Data Preparation for Machine Learning SINGLE-SELECT

A retail analytics company stores 40 TB of historical customer transaction logs in unlabeled .csv files across an Amazon S3 bucket. Several columns contain missing values, and the schema is not yet registered in the AWS Glue Data Catalog. An ML engineer must catalog the schema, clean and engineer features visually with minimal code, and store the prepared dataset for Amazon SageMaker training. 1. Run an AWS Glue crawler over the S3 bucket to infer schemas and populate the AWS Glue Data Catalog. 2. Run an AWS Glue DataBrew recipe job to impute missing values, apply feature encoding, and clean the dataset. 3. Write the transformed output dataset back to Amazon S3 in Apache Parquet format for SageMaker training. What is the correct chronological sequence of steps?

  1. A. 1 -> 2 -> 3
  2. B. 2 -> 1 -> 3
  3. C. 1 -> 3 -> 2
  4. D. 3 -> 1 -> 2
Reveal Verified Answer (A), Technical Explanation & Exam Hack

Correct Answer: Option A

First, the AWS Glue crawler inspects the raw CSV files in S3 to infer column schemas and register the table in the Glue Data Catalog (1). Second, AWS Glue DataBrew uses that cataloged dataset to run visual data cleaning and feature engineering recipes (2). Third, DataBrew outputs the cleaned dataset back to Amazon S3 in columnar Parquet format for downstream SageMaker training (3). Architectural Deep Dive: AWS Glue DataBrew is a visual, no-code data preparation service with 250+ pre-built transformations, automated data profiling, PII handling, and reusable recipes that data analysts and engineers can schedule across large S3, Redshift, and RDS datasets without writing Spark code. Option C is incorrect because this option either misapplies the AWS service outside its intended architectural pattern or violates the primary constraint (operational simplicity, cost efficiency, or target accuracy) specified in the scenario. Option D is incorrect because this option either misapplies the AWS service outside its intended architectural pattern or violates the primary constraint (operational simplicity, cost efficiency, or target accuracy) specified in the scenario.

Production Use Case: Enterprise data governance teams use Glue DataBrew recipes to standardize date formats, mask PII columns, and impute missing values across terabytes of daily S3 CSV drops before cataloging them in the Glue Data Catalog.
Exam Hack: When the stem emphasizes 'no-code visual interface', 'data profiling', or 'reusable cleaning recipes' with LEAST development effort, Glue DataBrew is your top contender.
Sample Q2 · Domain 4: ML Solution Monitoring, Maintenance, and Security SINGLE-SELECT

A company is building a web-based AI application by using Amazon SageMaker. The application will provide the following capabilities and features: ML experimentation, training, a central model registry, model deployment, and model monitoring. The application must ensure secure and isolated use of training data during the ML lifecycle. The training data is stored in Amazon S3. The company needs to use the central model registry to manage different versions of models in the application. Which action will meet this requirement with the LEAST operational overhead?

  1. A. Create a separate Amazon Elastic Container Registry (Amazon ECR) repository for each model.
  2. B. Use Amazon Elastic Container Registry (Amazon ECR) and unique tags for each model version.
  3. C. Use the SageMaker Model Registry and model groups to catalog the models.
  4. D. Use the SageMaker Model Registry and unique tags for each model version.
Reveal Verified Answer (C), Technical Explanation & Exam Hack

Correct Answer: Option C

The correct choice is C: Option C (Use the SageMaker Model Registry and model groups to catalog the models.). Amazon SageMaker Model Registry provides a centralized, versioned catalog using Model Groups where each trained iteration is registered as a versioned model package with metadata, metrics, lineage, and explicit approval states (PendingManualApproval, Approved, Rejected) that integrate natively with CI/CD pipelines. Why the distractors fail: Option A is incorrect because this option either misapplies the AWS service outside its intended architectural pattern or violates the primary constraint (operational simplicity, cost efficiency, or target accuracy) specified in the scenario. Option B is incorrect because this option either misapplies the AWS service outside its intended architectural pattern or violates the primary constraint (operational simplicity, cost efficiency, or target accuracy) specified in the scenario. Option D is incorrect because this option relies on manual tag tracking or raw container repositories rather than managed model package versioning and governance workflows.

Production Use Case: In enterprise MLOps platforms, every SageMaker Pipeline run registers its candidate artifact into a Model Group as 'PendingManualApproval'; once a Lead ML Engineer approves it in Studio, an EventBridge rule automatically triggers CodePipeline to deploy the production endpoint.
Exam Hack: Whenever a question combines 'central model catalog', 'manage model versions', or 'approval workflow before deployment', lock onto SageMaker Model Registry and Model Groups immediately.

Sample Q5 · Domain 1: Data Preparation for Machine Learning SINGLE-SELECT

A company is building a web-based AI application by using Amazon SageMaker. The application will provide the following capabilities and features: ML experimentation, training, a central model registry, model deployment, and model monitoring. The application must ensure secure and isolated use of training data during the ML lifecycle. The training data is stored in Amazon S3. The company needs to run an on-demand workflow to monitor bias drift for models that are deployed to real-time endpoints from the application. Which action will meet this requirement?

  1. A. Configure the application to invoke an AWS Lambda function that runs a SageMaker Clarify job.
  2. B. Invoke an AWS Lambda function to pull the sagemaker-model-monitor-analyzer built-in SageMaker image.
  3. C. Use AWS Glue Data Quality to monitor bias.
  4. D. Use SageMaker notebooks to compare the bias.
Reveal Verified Answer (A), Technical Explanation & Exam Hack

Correct Answer: Option A

The correct choice is A: Option A (Configure the application to invoke an AWS Lambda function that runs a SageMaker Clarify job.). Amazon SageMaker Clarify computes both pre-training data bias metrics (such as Class Imbalance, DPL, KL Divergence) and post-training model bias metrics, while using Kernel SHAP (SHapley Additive exPlanations) to generate global and local feature attribution scores and monitor ongoing bias or feature attribution drift. Why the distractors fail: Option B is incorrect because this option either misapplies the AWS service outside its intended architectural pattern or violates the primary constraint (operational simplicity, cost efficiency, or target accuracy) specified in the scenario. Option C is incorrect because this option performs one-off manual notebook inspection or re-architects the pipeline instead of updating or scheduling automated SageMaker Model Monitor baselines. Option D is incorrect because this option either misapplies the AWS service outside its intended architectural pattern or violates the primary constraint (operational simplicity, cost efficiency, or target accuracy) specified in the scenario.

Production Use Case: In regulated banking and healthcare ML systems, teams attach a SageMaker Clarify processing step inside SageMaker Pipelines to block any model whose Disparate Impact (DI) or SHAP feature attribution shifts beyond compliance thresholds.
Exam Hack: Remember the sibling split: Clarify = Bias + Explainability (SHAP); Model Monitor = Data/Model Quality Drift in production; Debugger = Internal training tensors and gradients.
