3 Exam Traps That Bridge MLA-C01 and MLA-C02

1. SageMaker Model Monitor vs SageMaker Clarify vs Bedrock Guardrails

Model Monitor detects production data/concept drift on live endpoints; Clarify measures pre/post-training demographic bias and SHAP feature importance; Bedrock Guardrails blocks PII, hallucinations, and prompt injections at LLM runtime.

2. RAG vs Continued Pre-Training vs Fine-Tuning

Default to RAG (Bedrock Knowledge Bases) for frequently changing private facts and verifiable citations; use PEFT/LoRA Fine-Tuning for strict output tone/JSON schema adherence; reserve Continued Pre-Training for massive unlabeled domain corpora.

3. Inference Components vs Serverless Inference

Choose SageMaker Inference Components when packing multiple foundation models or adapters onto shared GPU instances with per-model scaling; choose Serverless Inference for sporadic traffic that tolerates cold starts.
