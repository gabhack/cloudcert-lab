Sample Q1 · Domain 1: Fundamentals of AI and ML SINGLE-SELECT

A retail chain wants to implement its first Machine Learning project on Amazon SageMaker AI to predict monthly customer churn. The CTO asks the team to arrange the following four ML lifecycle stages in chronological order from project inception to production: 1. Feature engineering and data cleansing using SageMaker Data Wrangler. 2. Defining the business goal and framing the ML problem. 3. Model training, hyperparameter tuning, and metric evaluation. 4. Endpoint deployment and continuous monitoring with SageMaker Model Monitor. What is the correct sequence?

  1. A. 1 -> 2 -> 3 -> 4
  2. B. 2 -> 1 -> 3 -> 4
  3. C. 2 -> 3 -> 1 -> 4
  4. D. 1 -> 3 -> 2 -> 4
Reveal Verified Answer (B), Technical Explanation & Exam Hack

Correct Answer: Option B

Every ML lifecycle starts by defining the business goal and problem framing (2), followed by data preparation and feature engineering (1), then model training and evaluation (3), and finally deployment and continuous monitoring (4). Options A, C, and D place downstream technical tasks ahead of prerequisites.

Production Use Case: In enterprise MLOps, aligning the business KPI before touching data prevents building accurate models that solve the wrong business problem.
Exam Hack: Golden MLOps sequence: Business Goal (2) -> Data/Features (1) -> Train/Eval (3) -> Deploy/Monitor (4).
Sample Q2 · Domain 1: Fundamentals of AI and ML SINGLE-SELECT

A solutions architect is designing four workloads on Amazon SageMaker AI with different latency and payload requirements. Match each numbered scenario to the appropriate inference mode: 1. Credit card payment authorization requiring sub-30-millisecond responses 24/7. 2. An internal HR tool that receives sporadic queries during business hours and sits idle nights and weekends. 3. Processing 750 MB medical video files that take 12 minutes per request using an internal queue. 4. Scoring purchase propensity for 15 million customer records stored in Amazon S3 every Sunday night. Which option shows the correct matching?

  1. A. 1: Serverless Inference | 2: Real-Time Inference | 3: Batch Transform | 4: Asynchronous Inference
  2. B. 1: Real-Time Inference | 2: Asynchronous Inference | 3: Serverless Inference | 4: Batch Transform
  3. C. 1: Real-Time Inference | 2: Serverless Inference | 3: Asynchronous Inference | 4: Batch Transform
  4. D. 1: Batch Transform | 2: Serverless Inference | 3: Asynchronous Inference | 4: Real-Time Inference
Reveal Verified Answer (C), Technical Explanation & Exam Hack

Correct Answer: Option C

Real-Time Inference keeps endpoints warm 24/7 for millisecond latency (1). Serverless Inference scales down to zero during idle periods (2). Asynchronous Inference handles payloads up to 1 GB and processing times up to 1 hour with built-in queuing (3). Batch Transform scores massive offline S3 datasets without persistent endpoints (4).

Production Use Case: Matching traffic patterns to the right SageMaker AI inference mode prevents paying 24/7 GPU costs for nightly batch or intermittent internal workloads.
Exam Hack: ms 24/7 = Real-Time; Scale to 0 = Serverless; Up to 1 GB / 1 hr queued = Async; Offline S3 millions = Batch Transform.
Sample Q3 · Domain 1: Fundamentals of AI and ML MULTI-SELECT

A data science team trains a deep neural network on Amazon SageMaker AI to classify insurance claims. The model achieves 98.7% accuracy on the training dataset but drops to 61.4% accuracy on the validation dataset. Which TWO technical actions should the team take to resolve this issue? (Choose TWO)

  1. A. Apply regularization techniques such as Dropout or L1/L2 penalties and enable Early Stopping during training.
  2. B. Increase the number of training epochs from 50 to 500 and add more hidden layers to the neural network.
  3. C. Increase the size and diversity of the training dataset or apply Data Augmentation.
  4. D. Remove the validation split so the model trains on 100% of available records.
  5. E. Reduce the training dataset size and disable k-fold cross-validation.
Reveal Verified Answer (A, C), Technical Explanation & Exam Hack

Correct Answer: Option A, C

Very high training accuracy (98.7%) paired with low validation accuracy (61.4%) indicates Overfitting. Overfitting is mitigated by applying regularization (Dropout, L1/L2) and Early Stopping (A), as well as expanding training data diversity or using Data Augmentation (C). Adding more layers and epochs (B) worsens overfitting.

Production Use Case: Enabling Early Stopping in SageMaker AI training jobs both prevents overfitting and cuts unnecessary GPU billing hours.
Exam Hack: 99% Train vs 61% Validation = Overfitting -> Regularization (Dropout/L1/L2) + Early Stopping + More diverse data.
Sample Q4 · Domain 1: Fundamentals of AI and ML SINGLE-SELECT

A digital bank processes 2 million daily transfers where 99.85% are legitimate transactions and only 0.15% are actual fraud. A data scientist presents a classifier boasting 99.85% Accuracy, but the security team discovers the model caught zero fraudulent transfers all week. Which evaluation metric should the bank use to properly balance catching real fraud against avoiding false alarms on legitimate customers?

  1. A. Mean Squared Error (MSE).
  2. B. ROUGE-L.
  3. C. R-squared (R²).
  4. D. F1-Score (or Precision-Recall AUC).
Reveal Verified Answer (D), Technical Explanation & Exam Hack

Correct Answer: Option D

On heavily imbalanced datasets (99.85% vs. 0.15%), Accuracy is misleading because a model that always predicts 'legitimate' scores 99.85% while catching zero fraud. F1-Score (the harmonic mean of Precision and Recall) properly evaluates minority-class classification. MSE and R² are regression metrics, and ROUGE-L evaluates text summarization.

Production Use Case: In payment fraud pipelines, MLOps deployment gates validate F1-Score and Recall at specific precision thresholds rather than overall Accuracy.
Exam Hack: Imbalanced dataset (fraud/rare events) -> Ignore Accuracy and select F1-Score.
Sample Q5 · Domain 1: Fundamentals of AI and ML SINGLE-SELECT

A logistics company runs a regression model on Amazon SageMaker AI that predicts package delivery times using only 3 input variables. Because the model suffers from underfitting, the technical lead asks the team to increase the number of input variables by deriving new columns from timestamps, weather logs, and historical routes. Which process and AWS tool should the team use?

  1. A. Feature Engineering using Amazon SageMaker Data Wrangler.
  2. B. Hyperparameter Tuning using Amazon SageMaker Automatic Model Tuning.
  3. C. Model compilation using Amazon SageMaker Neo.
  4. D. Dimensionality reduction using Principal Component Analysis (PCA).
Reveal Verified Answer (A), Technical Explanation & Exam Hack

Correct Answer: Option A

Creating new input variables from raw data to improve model learning is Feature Engineering, which is visually accelerated by Amazon SageMaker Data Wrangler. Hyperparameter Tuning (B) adjusts training settings like learning rate or epochs—it never adds input features. PCA (D) reduces rather than increases feature count.

Production Use Case: Data scientists use SageMaker Data Wrangler to visually create time-window aggregations and interaction features before training.
Exam Hack: 'Increase the number of input variables' = Feature Engineering (Data Wrangler), NEVER Hyperparameter Tuning!
