3 High-Yield Microsoft Foundry Traps Tested on Both AI-901 & AI-103

1. Foundry Hub vs Foundry Project Isolation

Use a single Foundry Hub to centralize VNet Private Link networking, Key Vault, and shared connections across an organization, and create separate Foundry Projects to isolate each product squad's prompt flows, datasets, evaluations, and RBAC.

2. Serverless Pay-As-You-Go vs Provisioned Throughput Units (PTU)

Pick Serverless API deployments for bursty, unpredictable traffic with zero idle cost; pick PTU when strict p99 latency SLAs and steady high tokens-per-minute (TPM) capacity are mandatory.

3. Prompt Shields & Groundedness Detection

Defend production agents against indirect prompt injection (malicious instructions hidden inside retrieved RAG documents) using Azure AI Content Safety Prompt Shields alongside groundedness detection before returning answers to users.
