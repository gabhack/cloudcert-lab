Sample Q1 · Domain 1: Plan and Manage Azure AI Solutions SINGLE-SELECT

A multinational bank is onboarding four AI engineering squads (Treasury, Fraud, Retail Banking, and Wealth) into Microsoft Foundry. All squads must share one centralized Managed Virtual Network, one Azure Key Vault, and corporate Private Endpoints, while keeping each squad's uploaded datasets, evaluation runs, agents, and developer RBAC strictly isolated. What Foundry topology should the cloud architect deploy?

  1. A. Four separate Azure subscriptions with peered virtual networks and duplicated Key Vaults.
  2. B. One Microsoft Foundry Hub managing shared network and Key Vault infrastructure, with four separate Foundry Projects scoped by RBAC.
  3. C. One Microsoft Foundry Project shared by all squads using folder naming conventions to separate datasets.
  4. D. Four standalone Azure AI Services single-service accounts with shared subscription-level Owner roles.
Reveal Verified Answer (B), Technical Explanation & Exam Hack

Correct Answer: Option B

Option B is correct because a Microsoft Foundry Hub acts as the enterprise governance and infrastructure boundary (Managed VNet, Private Endpoints, Key Vault, shared Connections), while child Foundry Projects isolate each team's data, agents, evaluations, and RBAC cleanly. Option A fails because four subscriptions duplicate networking and Key Vault operations unnecessarily. Option C fails because folder naming conventions provide zero security isolation inside a single Project. Option D fails because standalone single-service accounts lack Foundry Project governance and Owner roles violate least privilege.

Production Use Case: Enterprise AI Centers of Excellence deploy one Hub per environment (Dev, Stage, Prod) and provision isolated Foundry Projects per business unit.
Exam Hack: Shared VNet and Key Vault + isolated team data/RBAC = 1 Foundry Hub + N Foundry Projects.
Sample Q2 · Domain 1: Plan and Manage Azure AI Solutions SINGLE-SELECT

A Python microservice hosted on Azure Container Apps calls a GPT-4o deployment in Microsoft Foundry using DefaultAzureCredential(). After disabling local key authentication (disableLocalAuth=true) on the Azure OpenAI resource, all inference requests begin returning HTTP 403 Forbidden. Which action resolves the error while adhering to Microsoft Zero Trust standards?

  1. A. Re-enable local key authentication and inject the primary API key via an environment variable.
  2. B. Assign the Container App's Managed Identity the Subscription Owner role.
  3. C. Assign the Container App's Managed Identity the Cognitive Services OpenAI User RBAC role on the Azure OpenAI resource.
  4. D. Switch the Python client from DefaultAzureCredential() to InteractiveBrowserCredential().
Reveal Verified Answer (C), Technical Explanation & Exam Hack

Correct Answer: Option C

Option C is correct because HTTP 403 Forbidden indicates Entra ID authentication succeeded, but the Managed Identity lacks data-plane RBAC authorization; Cognitive Services OpenAI User grants least-privilege inference access. Option A fails because re-enabling static API keys violates Zero Trust and keyless security mandates. Option B fails because Subscription Owner grants excessive administrative permissions. Option D fails because InteractiveBrowserCredential requires a human login popup and cannot run in a headless Container App.

Production Use Case: Production microservices on AKS, Container Apps, and App Service authenticate to Foundry exclusively via Managed Identity and Cognitive Services OpenAI User.
Exam Hack: HTTP 403 with DefaultAzureCredential -> Grant Cognitive Services OpenAI User RBAC.
Sample Q3 · Domain 1: Plan and Manage Azure AI Solutions SINGLE-SELECT

A global SaaS platform runs an enterprise support copilot backed by a Provisioned Throughput Unit (PTU) deployment in East US 2. During Monday morning peaks, traffic exceeds PTU capacity by 35%, triggering HTTP 429 errors for paying customers, while an internal QA team consumes 30% of the PTU quota running load tests. How should the AI engineer resolve both problems with minimal application code changes?

  1. A. Place Azure API Management (APIM) AI Gateway in front of Foundry, enforce per-subscription llm-token-limit policies, and configure a priority backend pool spilling overflow traffic to a Global Standard Pay-As-You-Go deployment.
  2. B. Triple the reserved PTU allocation 24/7 across all days of the week to absorb the Monday morning spike.
  3. C. Ask client frontend developers to implement a 60-second static sleep timer whenever an HTTP 429 occurs.
  4. D. Migrate the real-time customer support copilot to the Azure OpenAI Global Batch API.
Reveal Verified Answer (A), Technical Explanation & Exam Hack

Correct Answer: Option A

Option A is correct because APIM AI Gateway natively enforces per-tenant/team TPM quotas via llm-token-limit (blocking noisy QA neighbors) and automatically routes overflow HTTP 429 traffic from a priority-1 PTU backend to a priority-2 Pay-As-You-Go backend. Option B fails because tripling 24/7 PTU capacity wastes substantial budget for a short weekly spike. Option C fails because static 60-second frontend sleeps ruin user experience and do not throttle the QA team. Option D fails because Global Batch API is asynchronous with a 24-hour SLA and cannot serve real-time chat.

Production Use Case: SaaS vendors front Foundry with APIM AI Gateway to combine predictable PTU baseline latency with elastic Pay-As-You-Go spillover and tenant chargeback.
Exam Hack: Noisy neighbor quotas + PTU overflow -> APIM AI Gateway (llm-token-limit + backend pool).
Sample Q4 · Domain 1: Plan and Manage Azure AI Solutions SINGLE-SELECT

A European insurance provider must process 400,000 archived claim narratives every Sunday night to classify fraud indicators and generate structured summaries. The pipeline has a 12-hour completion window, must keep data processing strictly inside the European Union, and must minimize token spend without consuming weekday interactive chat TPM quota. Which deployment option should the team select?

  1. A. Regional Provisioned Throughput Units (PTU) dedicated solely to Sunday night runs.
  2. B. Global Standard Pay-As-You-Go with temperature set to 0.0.
  3. C. Serverless Managed Compute running a custom GPU cluster billed 24/7.
  4. D. Data Zone Batch (EU) API processing JSONL files asynchronously.
Reveal Verified Answer (D), Technical Explanation & Exam Hack

Correct Answer: Option D

Option D is correct because Data Zone Batch (EU) processes bulk JSONL files asynchronously within a 24-hour SLA at roughly 50% lower token cost, uses a separate batch quota pool, and pins data processing inside the European Union. Option A fails because reserving PTUs for a once-weekly batch job is prohibitively expensive. Option B fails because Global Standard can route requests outside the EU and charges full real-time token pricing. Option C fails because paying 24/7 GPU compute hours for a weekly batch job is inefficient.

Production Use Case: Regulated EU enterprises use Data Zone Batch to run overnight compliance audits and document summarization at half price while honoring GDPR residency.
Exam Hack: EU residency + offline bulk JSONL + 50% savings = Data Zone Batch (EU).
Sample Q5 · Domain 1: Plan and Manage Azure AI Solutions SINGLE-SELECT

A defense contractor operates an air-gapped facility with zero outbound internet connectivity and must run Azure AI Language PII detection and sentiment analysis over classified maintenance logs locally. Which deployment model satisfies this strict constraint?

  1. A. Azure OpenAI Global Standard accessed via a public HTTPS proxy.
  2. B. Azure AI Services Connected Docker Containers deployed on local Kubernetes.
  3. C. Azure AI Services Disconnected Docker Containers running with an approved commitment-tier license file.
  4. D. Microsoft Foundry Serverless API endpoints accessed through an Azure Private Endpoint.
Reveal Verified Answer (C), Technical Explanation & Exam Hack

Correct Answer: Option C

Option C is correct because Disconnected Containers run entirely offline in air-gapped environments using a commitment-tier license file without sending billing telemetry over the internet. Option B fails because Connected Containers still require periodic outbound internet access to transmit billing meter counts to Azure. Option D fails because Private Endpoints still connect back to Azure cloud regions and cannot operate in a physically air-gapped facility. Option A fails because public HTTPS proxies violate the zero-internet mandate.

Production Use Case: Defense, maritime, and critical-infrastructure operators deploy Disconnected Containers on local clusters when cloud connectivity is impossible.
Exam Hack: Air-gapped zero-internet facility = Disconnected Azure AI Services Containers.
