Sample Q1 · Domain 1: Fundamentals of Generative AI SINGLE-SELECT

During a quarterly technology briefing at a regional retail bank, the Chief Operating Officer asks how four proposed initiatives relate to each other: (1) a static if-then compliance alert engine, (2) a gradient-boosted model scoring credit-card churn probability, (3) a convolutional neural network inspecting scanned check signatures, and (4) a system drafting personalized wealth-advisory summaries. Which statement accurately explains the hierarchical relationship among AI, Machine Learning, Deep Learning, and Generative AI to guide the board's investment taxonomy?

  1. A. Generative AI is the broadest umbrella discipline that encompasses classical Machine Learning, Deep Learning, and static rule-based expert systems.
  2. B. Artificial Intelligence is the broadest field, Machine Learning is a subset of AI that learns patterns from data, Deep Learning is a neural-network subset of ML, and Generative AI is a subset of Deep Learning capable of creating new content.
  3. C. Machine Learning and Generative AI are mutually exclusive branches of computer science because Generative AI relies solely on deterministic rules rather than statistical training data.
  4. D. Deep Learning is a specialized subset of Generative AI used only when organizations need structured tabular predictions rather than unstructured text or imagery.
Reveal Verified Answer (B), Technical Explanation & Exam Hack

Correct Answer: Option B

Option B is correct because the standard technical hierarchy nests from broadest to most specialized: Artificial Intelligence (including rule-based systems) -> Machine Learning (learning from data, such as churn scoring) -> Deep Learning (multi-layered neural networks, such as check signature vision models) -> Generative AI (deep neural foundation models that synthesize novel text, images, audio, code, or video). Option A inverts the hierarchy by placing Generative AI above AI and classical ML. Option C is wrong because Generative AI is trained statistically on massive datasets via deep learning, not static rules. Option D reverses the Deep Learning / Generative AI nesting and misstates Deep Learning's primary strengths.

Production Use Case: Enterprise AI governance boards at financial institutions map portfolio proposals across the AI -> ML -> DL -> GenAI hierarchy so teams match classical ML (BigQuery ML / Vertex AI Tabular) to numerical forecasting and Gemini foundation models to content synthesis.
Exam Hack: Russian nesting dolls rule: AI (broadest) > Machine Learning (learns from data) > Deep Learning (multi-layer neural nets) > Generative AI (creates new content).
Sample Q2 · Domain 2: Google Cloud's Generative AI Offerings SINGLE-SELECT

A product innovation squad at a multinational insurance carrier built a working claims-triage prototype in two days using Gemini models inside Google AI Studio with a personal developer API key. Before launching the assistant to 4,500 licensed adjusters handling regulated policyholder records, the Chief Information Security Officer requires IAM role-based access control, VPC Service Controls data-exfiltration perimeters, Customer-Managed Encryption Keys (CMEK), and enterprise SLAs. What should the engineering director recommend?

  1. A. Continue running production traffic in Google AI Studio and rotate the shared API key every 24 hours via a cron job.
  2. B. Export the prototype prompts into a consumer Gemini web workspace and assign each adjuster an individual Gmail login.
  3. C. Migrate the Gemini workload from Google AI Studio to Vertex AI inside a governed Google Cloud project to gain IAM, VPC Service Controls, CMEK, and enterprise compliance guarantees.
  4. D. Replace Gemini with a self-built rule engine because Google Cloud does not support VPC Service Controls or CMEK for foundation models.
Reveal Verified Answer (C), Technical Explanation & Exam Hack

Correct Answer: Option C

Option C is correct because Google AI Studio is designed for rapid individual developer prototyping with lightweight API keys, whereas Vertex AI is Google Cloud's unified enterprise AI platform providing granular Cloud IAM, VPC Service Controls, CMEK, regional data residency, audit logging, and production SLAs. Option A fails because rotating API keys in AI Studio does not provide VPC-SC perimeters, CMEK, or enterprise governance. Option B violates enterprise security and privacy policies by routing regulated policyholder data through consumer accounts. Option D is factually false because Vertex AI natively supports VPC-SC, CMEK, and zero-data-training enterprise commitments.

Production Use Case: Enterprise digital teams rapidly iterate prompts and multimodal tests in Google AI Studio, then click 'Get Code' to deploy the production pipeline onto Vertex AI endpoints governed by organization-wide IAM, Cloud KMS CMEK, and VPC Service Controls.
Exam Hack: Google AI Studio = fast developer prototyping with API keys; Vertex AI = production enterprise scale with IAM, VPC-SC, CMEK, and SLAs.
Sample Q3 · Domain 3: Techniques to Improve Generative AI Model Output SINGLE-SELECT

A corporate legal operations team uses a Gemini model on Vertex AI to classify incoming vendor indemnification clauses into four internal risk tiers: TIER_1_AUTO_APPROVE, TIER_2_STANDARD_REDLINE, TIER_3_COUNSEL_REVIEW, and TIER_4_ESCALATE_GC. With a plain instruction naming the four labels, the model classifies obvious clauses well but inconsistently interprets subtle liability caps and occasionally invents extra label names. The team wants the fastest, lowest-cost way to improve classification consistency without training a custom model. What technique should they apply first?

  1. A. Add few-shot prompting by supplying 4 to 6 representative clause-and-tier examples inside the prompt to demonstrate boundary cases and exact output labels.
  2. B. Collect 50,000 labeled clauses and launch full supervised fine-tuning of a new base model before modifying the prompt.
  3. C. Raise the sampling temperature to 1.6 so the model explores broader legal interpretations for every clause.
  4. D. Switch from a text LLM to an Imagen diffusion model because image models enforce stricter classification taxonomies.
Reveal Verified Answer (A), Technical Explanation & Exam Hack

Correct Answer: Option A

Option A is correct because few-shot prompting embeds a small set of high-signal input/output examples directly in the prompt, anchoring both nuanced decision boundaries and exact label syntax at zero training cost and minimal latency overhead. Option B violates the GenAI adaptation hierarchy by jumping to expensive full fine-tuning before exhausting prompt engineering. Option C increases randomness and worsens label inconsistency instead of stabilizing classification. Option D is nonsensical because Imagen generates and edits images rather than classifying legal text.

Production Use Case: Legal, procurement, and compliance teams place 3 to 8 edge-case examples inside a Vertex AI prompt template (paired with structured output) to standardize clause triage before considering PEFT/LoRA adaptation.
Exam Hack: Zero-shot drifts on subtle edge cases or formatting -> upgrade to Few-Shot Prompting (3-6 concrete input/output examples) first.
Sample Q4 · Domain 4: Business Strategies for Successful GenAI Solutions SINGLE-SELECT

Over the past nine months, enthusiastic engineers across a global industrial manufacturer built more than 35 Generative AI prototypes during internal hackathons. Despite strong technical demos, not a single prototype has reached production because business unit presidents lack shared priorities, security approvals stall indefinitely, and no funding exists to operationalize pilots. Which organizational transformation pattern best resolves this 'pilot purgatory'?

  1. A. Shut down all grassroots employee experimentation permanently and outsource every future AI idea to external agencies.
  2. B. Allow each factory manager to purchase separate unapproved consumer AI subscriptions using corporate travel cards.
  3. C. Mandate that every engineering team pre-train its own proprietary foundation model from scratch before presenting to leadership.
  4. D. Combine top-down executive sponsorship (aligned strategic goals, budget, and governance guardrails) with structured bottom-up team experimentation.
Reveal Verified Answer (D), Technical Explanation & Exam Hack

Correct Answer: Option D

Option D is correct because Google Cloud's GenAI executive transformation playbook emphasizes pairing top-down executive sponsorship (clear business priorities, funding, security/governance pathways) with bottom-up experimentation (empowering frontline builders to surface real pain points) so winning pilots smoothly graduate into production. Option A kills frontline innovation and institutional learning. Option B creates shadow AI, data leakage, and compliance exposure. Option C wastes millions of dollars and years of effort without solving governance or executive alignment.

Production Use Case: Global enterprises pair an executive AI steering committee (setting ROI gates and fast-track security reviews) with bottom-up Vertex AI sandbox programs so promising prototypes graduate into funded production products.
Exam Hack: Stuck in hackathon/pilot purgatory = missing Top-Down Executive Sponsorship paired with Bottom-Up Experimentation.
Sample Q5 · Domain 1: Fundamentals of Generative AI SINGLE-SELECT

A healthcare logistics company is establishing a standardized Machine Learning lifecycle for its analytics and AI teams to move models reliably from raw operational records to sustained production value. Which sequence represents the proper end-to-end ML lifecycle order?

  1. A. Order 1 -> 2 -> 3 -> 4: (1) Deploy model endpoint to production -> (2) Ingest and clean raw operational data -> (3) Train and evaluate candidate models -> (4) Define business objective and feature definitions.
  2. B. Order 1 -> 2 -> 3 -> 4: (1) Ingest, clean, and prepare high-quality data with feature engineering -> (2) Train and tune candidate models on training splits -> (3) Evaluate accuracy, fairness, and business metrics on held-out test sets -> (4) Deploy to production and continuously monitor for data drift and performance decay.
  3. C. Order 1 -> 2 -> 3 -> 4: (1) Monitor production drift -> (2) Evaluate test accuracy -> (3) Clean raw training datasets -> (4) Train production model without validation.
  4. D. Order 1 -> 2 -> 3 -> 4: (1) Train deep learning models on uncleaned raw logs -> (2) Deploy directly to customers -> (3) Perform feature engineering after deployment -> (4) Ingest source data retroactively.
Reveal Verified Answer (B), Technical Explanation & Exam Hack

Correct Answer: Option B

Option B is correct because a disciplined ML lifecycle progresses sequentially from (1) data ingestion, cleaning, preparation, and feature engineering -> (2) model training/tuning -> (3) rigorous offline evaluation on held-out test datasets for quality and fairness -> (4) production deployment paired with ongoing drift and performance monitoring. Options A, C, and D scramble mandatory dependencies by deploying or monitoring before data preparation, training, and evaluation occur.

Production Use Case: Organizations orchestrate this exact lifecycle end-to-end in Vertex AI Pipelines, Vertex AI Model Registry, Vertex AI Evaluation, and Vertex AI Model Monitoring to prevent silent accuracy decay after go-live.
Exam Hack: ML Lifecycle Golden Sequence: Data Prep/Features -> Train -> Evaluate -> Deploy & Monitor Drift.
