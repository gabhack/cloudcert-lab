Sample Q1 · Domain 1: Cloud Concepts SINGLE-SELECT

A financial technology startup is designing its new digital payments platform. Instead of taking out a large bank loan to purchase physical servers, racks, and data center facilities before acquiring its first customer, the CFO decides to deploy the architecture on AWS and pay only for the compute seconds and storage gigabytes consumed each month. Which fundamental economic advantage of cloud computing is the company leveraging?

  1. A. Completely eliminating customer responsibility for application data security
  2. B. Trading capital expense (CapEx) for variable expense (OpEx)
  3. C. Trading variable expense (OpEx) for upfront capital expense (CapEx)
  4. D. Guaranteeing zero network latency through local hardware ownership
Reveal Verified Answer (B), Technical Explanation & Exam Hack

Correct Answer: Option B

B is correct because one of the six core advantages of cloud computing is trading upfront capital expense (CapEx: investing heavily in data centers and physical servers before using them) for variable expense (OpEx: paying only when consuming computing resources). C reverses the economic terms. A violates the Shared Responsibility Model. D is physically impossible.

Production Use Case: Launching a greenfield SaaS platform where initial seed capital is preserved for product engineering rather than tied up in depreciating server hardware.
Exam Hack: CapEx = Heavy upfront hardware investment; Variable Expense (OpEx) = Pay-as-you-go utility billing.
Sample Q2 · Domain 1: Cloud Concepts SINGLE-SELECT

A mid-sized retail chain stores 40 TB of product catalogs and sales history. If the company purchased enterprise storage hardware on its own, its unit cost per gigabyte would be high due to limited purchasing power with hardware vendors. By migrating to Amazon S3, the retailer achieves significantly lower per-gigabyte rates because AWS aggregates usage from hundreds of thousands of customers worldwide. What is this cloud computing benefit called?

  1. A. Automated horizontal elasticity
  2. B. Active-active high availability
  3. C. Benefiting from massive economies of scale
  4. D. Going global in minutes
Reveal Verified Answer (C), Technical Explanation & Exam Hack

Correct Answer: Option C

C is correct because cloud computing allows customers to benefit from massive economies of scale: aggregated usage from hundreds of thousands of customers enables AWS to achieve higher economies of scale, which translates into lower pay-as-you-go prices. A refers to scaling capacity up and down. D refers to global footprint. B refers to uptime resilience.

Production Use Case: A regional business getting enterprise-grade storage and compute unit pricing on AWS without buying petabytes of hardware.
Exam Hack: Aggregated usage of thousands of customers = Lower pay-as-you-go unit prices = Massive economies of scale.
Sample Q3 · Domain 1: Cloud Concepts SINGLE-SELECT

A concert ticketing company previously purchased 100 physical servers to handle traffic spikes whenever international tour tickets went on sale. However, for 90% of the year those servers sat idle wasting money, and during the biggest concert of the year 100 servers were still insufficient, causing the website to crash. By migrating to AWS, the company uses Amazon EC2 Auto Scaling to provision only the exact capacity required at any given minute. Which advantage of cloud computing solves this problem?

  1. A. End-to-end cryptographic data encryption
  2. B. Consolidated billing across member accounts
  3. C. Perpetual per-core software license standardization
  4. D. Stop guessing capacity
Reveal Verified Answer (D), Technical Explanation & Exam Hack

Correct Answer: Option D

D is correct because cloud computing eliminates guessing your infrastructure capacity needs. Instead of sitting on expensive idle resources or dealing with limited capacity during traffic spikes, you access as much or as little capacity as needed and scale dynamically. B is an AWS Organizations feature. A is a security control. C relates to on-premises licensing.

Production Use Case: Ticketing and flash-sale e-commerce sites that scale out from 4 to 200 instances during a launch and scale back in immediately afterward.
Exam Hack: Idle servers vs crashed servers from bad capacity forecasts = Stop guessing capacity.
Sample Q4 · Domain 1: Cloud Concepts SINGLE-SELECT

At a traditional pharmaceutical company, whenever the genomic research team needed a 50-server cluster to test a new molecular algorithm, the hardware procurement, racking, cabling, and OS setup process took 10 weeks. After migrating to AWS, scientists launch complete test environments in just a few minutes, dramatically reducing the time required to bring new therapies to market. Which key benefit of the AWS Cloud does this scenario describe?

  1. A. Increase speed and agility
  2. B. Passive retention of legacy servers (Retain)
  3. C. Dedicated physical socket isolation
  4. D. Mandatory upfront annual billing
Reveal Verified Answer (A), Technical Explanation & Exam Hack

Correct Answer: Option A

A is correct because in a cloud computing environment, new IT resources are only a click away, reducing the time to make those resources available to developers from weeks to just minutes. This results in a dramatic increase in agility for the organization since the cost and time it takes to experiment and develop are significantly lower.

Production Use Case: R&D and engineering squads spinning up ephemeral environments in minutes to validate features without waiting for hardware procurement.
Exam Hack: Weeks of IT procurement reduced to minutes for experimentation = Increase speed and agility.
Sample Q5 · Domain 1: Cloud Concepts SINGLE-SELECT

A maritime logistics company employed eight full-time engineers solely to replace failed hard drives, maintain backup diesel generators, manage industrial HVAC cooling, and cable switches in its private data center. Leadership decides to close the on-premises data center and migrate to AWS so those eight engineers can focus 100% of their time on building route-optimization algorithms for customers. Which advantage of cloud computing does this decision represent?

  1. A. Transferring legal ownership of business data to AWS
  2. B. Stop spending money running and maintaining data centers
  3. C. Replacing network encryption with physical security alone
  4. D. Guaranteeing that application code never requires updates
Reveal Verified Answer (B), Technical Explanation & Exam Hack

Correct Answer: Option B

B is correct because cloud computing lets organizations focus on projects that differentiate their business rather than the undifferentiated heavy lifting of racking, stacking, and powering physical servers in data centers. A, D, and C are incorrect statements.

Production Use Case: Transitioning infrastructure staff from physical hardware maintenance to building customer-facing logistics features and cloud automation.
Exam Hack: Stop racking/stacking/cooling servers and focus on customers = Stop spending money running and maintaining data centers.
